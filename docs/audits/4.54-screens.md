# Visual audit: screens changed in 4.54

Read-only check of release 4.54 (main fd36b8c). No app code was changed.

**How it was tested:** Playwright drove Chromium against a local copy of the app. Every request to Supabase was blocked, so the live project was never contacted. The steps were:

1. Import `tests/browser/files/anki-update-v1.apkg` into a new deck called "Update test".
2. Edit Beta's back, the same way `e2e-anki-update.mjs` does.
3. Import `anki-update-v2.apkg` into that deck to get the re-import preview.
4. Give the imported cards a multi-line front and back, which brings up the `fl-lead`/`fl-rest` layout.
5. Open Review, Browse (`#/browse`), and the Compare sheet (`openCompare`).

Each step was run in dark and light, at phone size (390x844) and desktop size (1280x800).

**Automatic checks:** No page scrolled sideways at either size (`scrollWidth` equals the viewport width). No page errors were logged.

Screenshots are in `docs/audits/4.54-shots/`.

## High

### 1. Import preview: switch box text touches the box border
- **Screen:** Import preview after loading an .apkg. Affects the "Update N cards you already have", "Overwrite N cards you may have edited here too", "Bring over my Anki progress" and "Make the reverse cards too" boxes, at every size and in both themes.
- **Problem:** The title and explanation start right against the left border, and the switch sits against the right border. In the desktop screenshot the box edge is at x=384 and the text starts at x=385. The cause is in `css/styles.css`: `.prog-row` (line 894) sets `padding:12px 14px`, but `.adv-row` (line 1348) comes later with the same specificity and sets `padding:12px 0`, so the side padding is lost. The same boxes appear in dark and light, so the owner sees this every time they re-import.
- **Evidence:** `import-reimport-desktop-dark.png`, `import-reimport-phone-dark.png`, `import-reimport-phone-light.png`
- **Fix:** Make the box rule win. Either use `.adv-row.prog-row{padding:12px 14px}` or move the `.prog-row` rule below `.adv-row`.

### 2. Compare sheet: line breaks are lost
- **Screen:** Compare, at both sizes and in both themes.
- **Problem:** A card whose front or back has several lines ("ephemeral / lasting a very short time / adjective, from Greek / What does it mean?") is shown as one run-on sentence: "ephemeral lasting a very short time adjective, from Greek What does it mean?". Review shows the same card as separate lines, with the first line leading. Compare exists to show the difference between two cards, so merging the lines makes it harder to read.
- **Evidence:** `compare-desktop-dark.png`, `compare-phone-light.png`. Compare with `review-front-phone-dark.png`.
- **Fix:** Render each side in Compare with the same `formatHTML` (and `leadLines`, if wanted) that Review uses, or at least add `white-space:pre-line` to the Compare text.

## Medium

### 3. Import preview: "Updates the card you already have" is also shown on the card that will be left alone
- **Screen:** Re-import preview with v2, with the "Overwrite 1 card…" switch off.
- **Problem:** The summary says "1 card differs from the file and will be left as it is", and that card is Beta, which was edited on this device. Even so, Beta's row shows the badge "Updates the card you already have", the same as Alpha and Gamma. The badge and the summary disagree.
- **Caveat:** `e2e-anki-update.mjs` counts five badges and passes. The badge may be counted on purpose, so the intended wording needs confirming.
- **Evidence:** `import-reimport-desktop-dark.png` (row 2, Beta)
- **Fix:** When the overwrite switch is off, give an edited card's row its own badge, for example "Kept as you edited it". Switch it to "Updates…" only when the overwrite switch is turned on.

### 4. Import preview: friendly notes are drawn in the error red
- **Screen:** Import preview, in both themes.
- **Problem:** The `.badge` style (`css/styles.css:736`) always uses `--again`/`--again-tint`, the colour for a failed review. As a result these neutral or good notes look like errors:
  - "Updates the card you already have"
  - "Cloze card c3: part of a note"
  - the summary line "1 card … will be left as it is"

  In dark mode it is pink text on a dark red tint. The test marks the descenders of "you already" as slightly clipped at the bottom edge of the badge on phone. This was seen in a 2x crop and is not measured.
- **Evidence:** `import-reimport-phone-dark.png`, `import-reimport-desktop-dark.png`
- **Fix:** Add a neutral or accent badge variant (`.badge.info` using `--accent` and `--accent-tint`) for update and cloze notes. Keep red for duplicates and problems. Give `.badge` `line-height:1.4` so descenders are not cut.

## Low

### 5. Toast lingers across screens and covers content
- **Screen:** Import preview, then Review.
- **Problem:** The toast "Added 6 cards to Update test" from the first import was still showing:
  - over row 1's badge on the re-import preview
  - over the front of the card in Review, in all four runs

  This was with reduced motion on (the test default), so a real device may show it for less time.
- **Evidence:** `import-reimport-phone-dark.png`, `review-front-phone-dark.png`
- **Fix:** Clear the toast when the route changes, or place it above the bottom action bar instead of over content.

### 6. Review back: the front's first line is dimmed but still large
- **Screen:** Review, back side, phone.
- **Problem:** The front recap ("ephemeral") is grey and bold above the divider. It competes a little with the answer "fleeting". This is a judgement call: everything is readable and the contrast is fine. The `--text-2` lines measure rgb(168,172,189) on dark and rgb(70,73,89) on light.
- **Evidence:** `review-back-phone-light.png`
- **Fix (optional):** Make `.flash-recap .fl-lead` the same size as the rest of the recap.

## Checked, no problem found
- **Review front (`fl-lead`/`fl-rest`):** The lead line is larger and the other lines are smaller and quieter, at both sizes and in both themes (`review-front-phone-dark.png`). It only applies when the first line is at most 18 characters. A 38-character first line correctly stays plain.
- **Browse:** No sideways scroll and no clipping beyond the intended one-line ellipsis on card previews (`browse-desktop-dark.png`).
- **Sticky "Update 5, add 2 cards…" button:** Readable in both themes.
